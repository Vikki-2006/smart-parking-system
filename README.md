## ✨ Why Smart Parking System?

The **Smart Parking System** is a full-stack web application designed to simplify and automate parking management.

Instead of relying on manual parking allocation and monitoring, the system provides a centralized platform for administrators to manage parking slots, vehicles, QR-based entry, exits, and parking availability.

### Key capabilities

- 🅿️ **Automatic parking slot allocation**
- 🚗 **Vehicle entry & exit management**
- 📱 **QR-based parking identification**
- 📊 **Real-time parking availability**
- 🔐 **Admin authentication**
- 🗺️ **Google Maps navigation**
- 🗄️ **SQLite database management**
- 🎨 **Modern responsive dashboard**
