## ✨ Why Smart Parking System?

The **Smart Parking System** is a full-stack web application designed to simplify and automate parking management.

Instead of relying on manual parking allocation and monitoring, the system provides a centralized platform for administrators to manage parking slots, vehicles, QR-based entry, exits, and parking availability.

### Key capabilities

- 🅿️ **Automatic parking slot allocation**
- 🚗 **Vehicle entry & exit management**
- 📱 **QR-based parking identification**
- 📊 **Real-time parking availability**
- 🔐 **Admin authentication**
- 🗺️ **Google Maps navigation**
- 🗄️ **SQLite database management**
- 🎨 **Modern responsive dashboard**

# 🚀 Features

### 🔐 Admin Authentication

Secure administration system with:

- Admin login
- Protected dashboard
- Session management
- Logout functionality

---

### 🅿️ Smart Parking Allocation

The system automatically manages parking slots based on availability.

- Automatic slot assignment
- Available slot detection
- Occupied slot monitoring
- Slot status management
- Automatic slot release after exit

---

### 🚗 Vehicle Entry & Exit

Complete vehicle lifecycle management.

- Vehicle registration
- Vehicle entry tracking
- Vehicle exit tracking
- Parking duration tracking
- Automatic slot release

---

### 📱 QR Code Parking

QR codes make parking identification faster and easier.

- QR code generation
- QR-based vehicle entry
- QR code scanning
- Parking slot identification
- Quick parking information access
